# 产品电商图搭建工作流

这是一套用于从产品信息到电商平台交付图的标准化工作流，适用于主图、详情图、场景图、卖点图、活动图和多平台适配图的批量生产。

## 1. 工作流目标

- 建立统一、可复用的电商图生产流程。
- 降低重复沟通成本，提升出图效率与质量稳定性。
- 保证图片符合品牌规范、平台规则和转化目标。
- 支持单品上新、活动大促、套装组合和多渠道分发。

## 2. 角色分工

| 角色 | 主要职责 | 关键产出 |
| --- | --- | --- |
| 运营 / 产品负责人 | 明确商品定位、平台规则、营销目标和上架计划 | 商品资料、卖点清单、平台尺寸要求 |
| 策划 / 文案 | 提炼核心卖点、转化话术和图片结构 | 图片脚本、标题文案、利益点文案 |
| 设计师 | 搭建视觉版式、执行出图和多尺寸适配 | 设计源文件、导出图、切图文件 |
| 摄影 / 3D / AI制图 | 提供产品素材、场景素材或渲染图 | 产品白底图、场景图、细节图 |
| 审核人 | 校对信息准确性、品牌一致性和平台合规性 | 审核意见、上线确认 |

## 3. 输入资料清单

启动设计前，应收集并确认以下资料：

### 3.1 商品基础资料

- 商品名称、型号、规格、颜色、材质、尺寸、重量。
- 价格、优惠信息、套餐组合、赠品信息。
- 适用人群、使用场景、核心痛点和购买理由。
- 竞品链接、竞品图片、差异化优势。

### 3.2 视觉素材

- 产品正面、侧面、背面、细节、包装图。
- 产品透明底 PNG 或高质量抠图素材。
- 品牌 Logo、品牌色、字体规范、图标规范。
- 场景图、模特图、使用过程图、质检或认证图。

### 3.3 平台规范

- 图片尺寸、文件格式、大小限制。
- 是否允许文字、边框、促销贴纸、对比图。
- 主图白底要求、禁用词、价格展示规则。
- PC 端、移动端、小程序、社媒渠道的适配要求。

## 4. 标准生产流程

### 阶段一：需求确认

1. 明确本次图片类型：主图、详情页、活动图、广告图或全套素材。
2. 确认目标平台：淘宝、天猫、京东、拼多多、抖音、小红书、亚马逊或独立站。
3. 明确转化目标：点击率、加购率、详情停留、活动转化或品牌展示。
4. 输出《电商图需求简表》。

**交付物：**需求简表、商品资料包、平台规则说明。

### 阶段二：卖点拆解

1. 从商品属性中提炼 3-5 个一级卖点。
2. 将卖点转化为用户利益点，例如“防水材质”转化为“雨天也能安心使用”。
3. 区分主卖点、辅助卖点、信任背书和促销信息。
4. 建立图片信息层级：第一眼看什么、第二眼理解什么、第三眼被什么打动。

**交付物：**卖点矩阵、文案初稿、图片信息优先级。

### 阶段三：图片结构规划

根据不同图片类型规划结构：

#### 主图结构

1. 首图：产品主体 + 核心利益点 + 品牌识别。
2. 第二张：核心功能或核心场景。
3. 第三张：差异化卖点或竞品对比。
4. 第四张：细节、材质、工艺或品质背书。
5. 第五张：套餐、规格、服务或促销信息。

#### 详情页结构

1. 痛点引入：用户为什么需要它。
2. 产品解决方案：产品如何解决问题。
3. 核心卖点展开：功能、材质、工艺、体验。
4. 使用场景：增强代入感。
5. 参数规格：降低决策疑虑。
6. 品牌 / 认证 / 售后：增强信任。
7. 购买引导：套餐、优惠、服务承诺。

**交付物：**图片脚本、页面结构草图、信息流顺序。

### 阶段四：视觉风格设定

1. 确定视觉关键词：高级、科技、温暖、专业、极简、潮流等。
2. 确定主色、辅助色、强调色。
3. 确定字体层级：标题、副标题、说明文字、参数文字。
4. 确定构图方式：居中展示、左右分栏、场景融合、卡片式模块、对比式模块。
5. 建立设计参考板，避免设计方向分歧。

**交付物：**风格板、配色方案、字体规范、参考图集合。

### 阶段五：素材处理

1. 产品抠图、修瑕、调色、统一光影。
2. 场景素材筛选或生成，确保与产品角度和光源一致。
3. 图标、标签、认证元素统一风格。
4. 为不同平台准备安全边距和裁切版本。

**交付物：**标准化素材库、透明底产品图、场景底图、图标组件。

### 阶段六：设计执行

1. 优先制作首图或关键详情图，先确认整体方向。
2. 确认后批量延展同系列图片。
3. 控制每张图的信息密度，避免堆砌文字。
4. 保持产品主体清晰，标题可读，卖点突出。
5. 按平台尺寸导出图片。

**交付物：**设计初稿、源文件、导出图。

### 阶段七：审核与修改

审核应覆盖以下维度：

- 商品信息是否准确。
- 卖点表达是否清晰。
- 是否存在平台违禁词或夸大宣传。
- 价格、促销、规格、参数是否与后台一致。
- 图片在手机端是否清晰可读。
- 品牌风格是否统一。

**交付物：**审核清单、修改记录、最终确认稿。

### 阶段八：导出与归档

1. 按平台命名规则导出图片。
2. 保留设计源文件、字体说明、素材来源和最终图。
3. 记录版本号，避免多人协作时文件混乱。
4. 归档复盘数据，为后续优化提供依据。

**交付物：**上线图片包、源文件包、归档记录。

## 5. 文件命名规范

推荐命名格式：

```text
品牌_产品名_SKU_平台_图片类型_序号_版本号.格式
```

示例：

```text
ABC_保温杯_Red500ml_Tmall_Main_01_v1.jpg
ABC_保温杯_Red500ml_Tmall_Detail_03_v2.jpg
```

## 6. 常用图片规格模板

| 场景 | 建议尺寸 | 说明 |
| --- | --- | --- |
| 电商主图 | 800×800 / 1000×1000 px | 适合多数国内平台 |
| 详情页宽图 | 750 px 宽 | 移动端详情常用宽度 |
| 活动横幅 | 1920×600 px | 店铺首页或活动页 |
| 社媒种草图 | 1080×1440 px | 小红书、朋友圈等竖版展示 |
| 短视频封面 | 1080×1920 px | 抖音、快手等竖屏封面 |
| 独立站商品图 | 1200×1200 px | 兼顾高清与加载速度 |

> 实际交付前应以目标平台最新规则为准。

## 7. 质量检查清单

上线前逐项确认：

- [ ] 图片尺寸、格式、大小符合平台要求。
- [ ] 产品外观、颜色、规格展示准确。
- [ ] 文案无错别字、无歧义、无违规词。
- [ ] 核心卖点在 3 秒内可被识别。
- [ ] 移动端预览文字清晰可读。
- [ ] 图片风格与品牌调性一致。
- [ ] 促销价格、赠品、服务承诺与后台一致。
- [ ] 所有素材拥有可用授权或来源记录。
- [ ] 文件命名清晰，版本可追踪。

## 8. 复盘与优化

图片上线后建议跟踪：

- 曝光量、点击率、收藏加购率、转化率。
- 主图点击表现与竞品对比。
- 详情页跳出位置和停留时长。
- A/B 测试不同首图、卖点文案和视觉风格。
- 根据数据沉淀高转化版式和行业模板。

## 10. 推荐交付节奏

| 时间节点 | 工作内容 |
| --- | --- |
| T+0 | 需求确认、资料收集、卖点拆解 |
| T+1 | 图片脚本、风格板、首图方向稿 |
| T+2 | 全套图片初稿 |
| T+3 | 审核修改、平台适配、最终导出 |
| 上线后 7 天 | 数据复盘、优化下一版图片 |
